# 滑动窗 FFT 幅值锯齿/跳变问题分析

## 问题简述

使用滑动窗 + FFT 提取特定频率的电压/电流幅值时，谐波分量（26.6 Hz、73.5 Hz）的幅值曲线出现锯齿状振荡，且每隔一定时间发生明显跳变。

## 环境参数

| 参数 | 初始值 | 修改后 |
|------|--------|--------|
| 窗长 `t_span` | 1 s | 10 s |
| 频率分辨率 Δf | 1 Hz | 0.1 Hz |
| 步长 `window_step` | 100 采样点 | 10 采样点 |
| 采样率 `fs` | 1000 Hz | 1000 Hz |
| 目标频率 | 26.6 / 50 / 73.5 Hz | 26.6 / 50 / 73.5 Hz |
| 窗函数 | 矩形窗（无窗） | 矩形窗（无窗） |

## 根因 1：目标频率不在 FFT bin 上（t_span=1 时）

`f_fft_simple` 的频率轴为整 Hz 间隔（Δf = 1 Hz），而 26.6 Hz 和 73.5 Hz 不是整数，只能取最近 bin：

| 目标频率 | 最近 bin | 偏差 |
|---------|----------|------|
| 26.6 Hz | 27 Hz | +0.4 Hz |
| 50 Hz | 50 Hz | 0（对齐） |
| 73.5 Hz | 73 或 74 Hz | ±0.5 Hz |

### 扇形损耗（scalloping loss）

信号频率偏离 bin 中心时，矩形窗的 Dirichlet 核在该 bin 处产生的幅值衰减量取决于**截断相位**（即信号在窗口起点处的相位）。

窗每次滑动 100 采样点（0.1 s），截断相位变化：

```
26.6 Hz × 0.1 s = 2.66 周期 → 小数部分 0.66 周期 ≈ 238°
```

截断相位每周不同 → 泄漏到 27 Hz bin 的能量每周不同 → 幅值振荡。

### 跳变周期 = 窗宽

步长 0.1 s，10 步 = 1 s = 窗宽。此时新旧窗口从重叠变为邻接，截断相位循环闭合，形成肉眼可见的**1 秒周期跳变**。

## 根因 2：t_span 改 10 未解决（电网频率漂移）

t_span=10 虽让 Δf 变为 0.1 Hz，理论上看 26.6、50、73.5 都精确落在 bin 上，但：

**电网实际频率不是精确的 50.0000 Hz**，而是在 49.95~50.05 Hz 之间漂移。即使只偏 0.02 Hz，信号仍不在 bin 中心，扇形损耗依然存在。

### 基波的旁瓣泄漏是主要干扰源

矩形窗第一旁瓣仅 -13 dB。50 Hz 基波幅值远大于谐波，其旁瓣能量泄漏到相邻 bin，且泄漏量随窗口滑动变化——叠加到谐波测量结果上，造成锯齿。

### 跳变周期变化

t_span=10、step=10 时，窗宽 = 10 s，步长 = 0.01 s。1000 步后窗口才邻接，跳变周期从 1 s 变为 **10 s**，但问题本质不变。

## 故障排查 Checklist

1. **检查 50 Hz 曲线是否平滑** — 如果 50 Hz 也有轻微锯齿 → 主因是基频偏移 bin 中心
2. **对比正序分量 vs 单相幅值** — 正序分量因三相平均，振荡幅度通常更小
3. **50 Hz 完全平滑但谐波锯齿** → 主因是基波旁瓣泄漏

## 解决方向

调 `t_span` 无法根治，因为永远无法让 bin 精确对准未知的实际频率。

| 方案 | 原理 | 效果 |
|------|------|------|
| 加窗函数（Hann / Hamming） | 旁瓣可压到 -43 dB 以下 | 谐波测值不再被基波泄漏干扰 |
| 插值 FFT（3 点或 5 点） | 从相邻 bin 拟合真实频率和幅值 | 补偿 scalloping loss，不需对准 bin |
| 窗函数 + 插值结合 | Hann 窗抑制旁瓣 + 插值补偿主瓣衰减 | 最佳效果 |

### 窗函数选择参考

| 窗类型 | 主瓣宽度 | 最高旁瓣 | 幅值修正需求 |
|--------|---------|---------|-------------|
| 矩形 | 2Δf | -13 dB | 无（仅 bin 中心对准时） |
| Hann | 4Δf | -32 dB | 需乘 2 |
| Hamming | 4Δf | -43 dB | 需乘 1.85 |
| Flat-top | ~5Δf | -44 dB | 标量修正即可 |

> **注意**：代码中的 `f_fft_simple` 目前未应用任何窗函数，等价于矩形窗。加窗后需要在 FFT 幅值上乘以相应系数以恢复正确幅值。
